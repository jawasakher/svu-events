# دليل فعاليات الجامعة الافتراضية السورية (SVU Events Directory)

> منصة وويب تفاعلية متكاملة لعرض وإدارة الفعاليات والأنشطة الأكاديمية والطلابية والتقنية في الجامعة الافتراضية السورية (SVU).

🌐 **[زيارة الموقع المباشر](https://svu-events.jawasakher.workers.dev/)**

---

## 🌟 مميزات المشروع (Features)

- **عرض الفعاليات البارزة والأسبوعية:** شريحة تفاعلية (Carousel) تعرض أبرز الفعاليات مع تحديث تلقائي للمعلومات.
- **التصفية المتقدمة (Filtering):** إمكانية البحث السريع وتصفية الفعاليات حسب الفئة (ثقافي، تقني، علمي، إبداعي، رياضي، اجتماعي)، المكان، وتاريخ البداية والنهاية.
- **تفاصيل الفعالية الشاملة:** صفحة خاصة لكل فعالية تعرض الوصف التفصيلي، المواعيد، موقع الفعالية (مع خريطة/صورة المكان)، ومعرض صور خاص بالفعالية، بالإضافة إلى اقتراح فعاليات ذات صلة.
- **تصدير إلى التقويم (ICS Export):** إمكانية تنزيل ملف تقويم بصيغة `.ics` لإضافة الفعالية مباشرة إلى Google Calendar أو Outlook.
- **مشاركة الفعاليات:** دعم واجهة المشاركة الأصلية للمتصفح (Web Share API) مع نسخ الرابط بالحافظة.
- **حجز المقاعد:** نظام حجز تفاعلي داخل نافذة منبثقة (Bootstrap Modal) مع التحقق من صحة المدخلات.
- **الوضع الليلي (Dark Mode):** دعم كامل للتبديل بين الوضع الفاتح والداكن مع حفظ تفضيل المستخدم في `localStorage`.
- **تصميم متجاوب بالكامل (RTL & Responsive):** مبني خصيصاً للدعم الكامل للغة العربية واتجاه RTL باستخدام Bootstrap 5.3 RTL.

## 📂 هيكلية المشروع (Project Structure)

```text
svu-events/
├── index.html            # الصفحة الرئيسية (Slider, Quick Categories, Latest Events)
├── events.html           # صفحة استعراض جميع الفعاليات مع الفلاتر المتقدمة
├── event.html            # صفحة تفاصيل الفعالية، حجز المقاعد، والتصدير للتقويم
├── about.html            # صفحة عن الدليل وأهداف المنصة وفريق العمل
├── contact.html          # صفحة اتصل بنا مع نموذج مراسلة وتحقق من المدخلات
└── assets/
    ├── css/
    │   └── styles.css    # تنسيقات CSS مخصصة والتصميم المتجاوب والوضع الليلي
    ├── js/
    │   └── main.js       # المنطق البرمجي، إدارة الفلاتر، حجز المقاعد، وحماية XSS
    └── img/              # صور الفعاليات، المواقع، الشعار، وصور الفريق
```

## 🚀 تشغيل المشروع محلياً (Getting Started)

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/jawasakher/svu-events.git
   ```
2. **فتح المشروع:**
   افتـح ملف `index.html` في أي متصفح حديث، أو استخدم ميزة **Live Server** في محرر VS Code لتشغيل خادم محلي.
